# F-021 — Import .ics : règles de récurrence ou dates invalides → erreur 500

- **Gravité** : Basse
- **Exigence** : SEC-06 / BDD-06
- **Trouvée par** : attaquant, manche 2, le 2026-11-27
- **Route / fichier** : `POST /agenda/import` — `backend/business/calendar_ics.py:54-58` (`int(...)` et `_parse_dt(UNTIL)` hors du `try`), `% interval` avec `INTERVAL=0`
- **Statut** : ouvert (contournement non corrigé, duel arrêté)

## Reproduction

Un événement par fichier, avec une `RRULE` ou un `DTSTART` piégé :

| Charge | Exception |
| --- | --- |
| `RRULE:FREQ=DAILY;INTERVAL=0`, `FREQ=WEEKLY;INTERVAL=0` | `ZeroDivisionError` |
| `RRULE:FREQ=DAILY;INTERVAL=abc` | `ValueError` |
| `RRULE:FREQ=DAILY;COUNT=x` | `ValueError` |
| `RRULE:FREQ=WEEKLY;UNTIL=2030` | `ValueError` |
| `DTSTART:99991231T235959` | `OverflowError` |

Résultat observé : 500 (exception non gérée), import abandonné.

Résultat attendu : événement ignoré ou message propre, jamais de 500.

Conforme : `INTERVAL=-1`, `BYDAY=ZZ`, `DTSTART` `00000101`, `20260230`, `2026`, `abc` ne plantent pas.

## Correction (rempli par le défenseur)

- Fichiers modifiés : `backend/business/calendar_ics.py` (`_positive_int`, `_expand`, `_occurrences`)
- Principe : une règle invalide (INTERVAL ou COUNT nul, négatif ou non numérique, UNTIL mal formé) n'est pas dépliée : seule l'occurrence de départ est gardée. Un événement dont les dates sortent des limites (`OverflowError`, `ValueError`, an 1 ou an 9999) est ignoré et compté dans le message. Plus d'exception, donc plus de 500.
