# F-09 — Aucun quota de générations LLM par utilisateur

- **Gravité** : Moyenne
- **Exigence** : SEC-08
- **Trouvée par** : attaquant, manche 3, le 2026-11-27
- **Route / fichier** : `POST /reviser/<id>/qcm`, `/reviser/<id>/exercices`, `/reviser/<id>/notebooks`, `/stages/lettres` — `backend/plugins/revision/service.py`, `backend/plugins/stages/service.py`
- **Statut** : reproduit

## Reproduction

LLM simulé (`FauxGroq` : l'appel HTTP à Groq est remplacé, aucune requête ne part ; clé factice).

1. Un utilisateur enchaîne 21 générations le même jour (7 QCM, 7 lettres, 7 séries d'exercices).
2. Les 21 partent au LLM : **21 appels**.

Impact : coût LLM sans limite (l'inscription est libre et F-03 ne limite que la connexion) ; un compte peut
épuiser le quota ou le budget du fournisseur pour tout le site.

Résultat attendu : 20 générations LLM par utilisateur et par jour (QCM, exercices, notebooks, lettres, photos
confondus), configurable ; la 21e refusée avec un message (le générateur par règles peut prendre le relais).
Témoin : le quota d'un utilisateur ne bloque pas les autres.

Note : l'injection de prompt (consignes cachées dans un PDF) ne se vérifie pas sans vrai modèle ; ses effets
observables (réponse de mauvaise forme, champs énormes, HTML) sont couverts par F-033 et par les tests XSS.

## Correction (rempli par le défenseur)

- Fichiers modifiés : `backend/dao/groq.py` (`charge_quota`, `QuotaError`, appel dans `chat`), `backend/dao/llm_usage.py` (nouveau), `backend/dao/db.py` (migration 3 : table `llm_usage`), `backend/plugins/revision/ai.py` (`_ask_claude`), `backend/config.py` (`LLM_DAILY_QUOTA` = 20)
- Principe : un passage obligé avant chaque appel à un modèle (`groq.chat`, utilisé par les QCM, exercices, notebooks, lettres et photos, et `_ask_claude` pour Claude) réserve une génération pour l'utilisateur connecté. Le compteur par utilisateur et par jour est incrémenté de façon atomique (`UPDATE … SET count = count + 1 WHERE count < limite`, validé tout de suite) : des demandes simultanées ne dépassent pas la limite. La 21e génération lève `QuotaError` (une `GroqError`, déjà gérée par chaque fonction) avec le message « Tu as utilisé tes 20 générations par l'IA du jour : réessaie demain. » ; le QCM retombe sur le générateur par règles et la lettre sur la lettre type. La migration 3 est additive et réversible (`DROP TABLE llm_usage`).
