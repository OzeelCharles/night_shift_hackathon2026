# F-031 — Exigence manquante : aucun filtre de mots interdits (F-12)

- **Gravité** : Basse
- **Exigence** : SEC-05 / F-12
- **Trouvée par** : attaquant, manche 3, le 2026-11-27
- **Route / fichier** : `POST /inscription`, `POST /profil` — `backend/business/moderation.py` et `backend/data/mots_interdits.txt` absents
- **Statut** : reproduit

## Reproduction

Le cahier exige un module pur `backend/business/moderation.py`, une liste `backend/data/mots_interdits.txt`, une
détection insensible à la casse, aux accents et aux substitutions (`@`→a, `0`→o, `1`→i, lettres répétées,
séparateurs), appliquée aux textes visibles par d'autres (d'abord le nom d'utilisateur), avec un message clair
qui ne répète pas le mot.

Tests d'acceptation (32 cas, par l'inscription et le profil) :

- 10 vrais positifs : `connard`, `Connard`, `CONNARD`, `salope`, `enculé`, `encule`, `pute`, `sale con`,
  `Gros connard 93`, `nazi` → **tous acceptés aujourd'hui** ;
- 12 variantes déguisées : `c0nn@rd`, `C0NN4RD`, `c.o.n.n.a.r.d`, `c.o.n`, `s@l0pe`, `e n c u l é`, `connnnnnard`,
  `CoNnArD`, `p-u-t-e`, `s_a_l_o_p_e`, `€ncul€`, `c-0-n-n-4-r-d` → **toutes acceptées** ;
- 10 faux positifs à laisser passer : `Concarneau`, `analyse`, `Scunthorpe`, `Constance`, `computer`, `salopette`,
  `Raconteur`, `Conan`, `Léa Dupont`, `Deconinck` → acceptés (à garder ainsi) ;
- message de refus non vide et sans le mot refusé ; même filtre sur `POST /profil`.

## Correction (rempli par le défenseur)

- Fichiers modifiés : `backend/business/moderation.py` (nouveau), `backend/data/mots_interdits.txt` (nouveau), `backend/dao/banned_words.py` (nouveau), `backend/business/accounts.py` (`validate_username`, `validate_account`), `backend/services/auth_service.py`, `backend/services/admin_service.py`, `backend/tests/test_moderation.py` (nouveau)
- Principe : module pur : le texte est mis en minuscules, les symboles substitués (@ € $ ! |_|), les accents retirés et le texte découpé en mots ; les chiffres sont substitués dans les mots (0→o, 1→i ou l, 3→e, 4→a…), les lettres répétées réduites et le pluriel en -s/-x retiré. Les lettres isolées sont recollées (« c.o.n », « e n c u l é ») et les paires de mots voisins testées (« ta gueule »). Un terme doit former un mot entier, ce qui laisse passer « Concarneau », « salopette » ou « computer ». Seuls les termes marqués `*` dans la liste sont cherchés à l'intérieur des mots (« grosconnard »). Le refus donne un message clair qui ne répète pas le mot. Le filtre s'applique au nom d'utilisateur à l'inscription, au profil et dans l'administration.
