# F-043 — Exigence manquante : aucun journal structuré ni journal d'audit admin (SEC-10)

- **Gravité** : Basse
- **Exigence** : SEC-10 / F-12
- **Trouvée par** : attaquant, manche 4, le 2026-11-28
- **Route / fichier** : toute l'application — `backend/services/auth_service.py`, `backend/services/admin_service.py`
- **Statut** : reproduit

## Reproduction

Journaux captés sur tous les loggers Python pendant chaque action :

- connexion échouée, connexion réussie, 6 échecs suivis d'un blocage : **aucune ligne JSON** (aucune ligne du tout) ;
- actions admin (création, réinitialisation du mot de passe, désactivation, suppression d'un compte) : **aucune
  ligne JSON** ; **pas de table `audit_log`** ; rien de consultable dans `/admin`.

Impact : aucune trace d'une attaque (force brute, élévation, suppression de comptes), aucune imputabilité des
actions admin.

Résultat attendu (SEC-10) : une ligne JSON par événement (connexions, blocages, actions admin, refus CSRF et SSRF,
quotas), jamais de mot de passe, de jeton ni de clé ; table `audit_log` des actions admin, visible dans `/admin`.

Conforme (testé) : aucun mot de passe n'apparaît aujourd'hui dans les journaux (il n'y en a pas) ; `/admin` reste
interdit à un utilisateur simple.
