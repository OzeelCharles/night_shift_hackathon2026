# F-037 — Exception en cours de requête : la base est annulée mais le fichier déposé reste sur le disque

- **Gravité** : Basse
- **Exigence** : BDD-04
- **Trouvée par** : attaquant, manche 4, le 2026-11-28
- **Route / fichier** : `POST /matieres/<id>/documents` — `backend/services/subject_service.py` (`save_documents` : `f.save` avant la fin de la transaction)
- **Statut** : reproduit

## Reproduction

1. Une panne est simulée après le dépôt (`planning_service.update` remplacé par une fonction qui lève une exception).
2. `POST /matieres/1/documents` avec `cours.md`.

Résultat observé : 500 ; la ligne `documents` est bien annulée (rollback de `close_db`), mais le fichier
`<uuid>_cours.md` reste dans `uploads/<user_id>/`, sans ligne en base : il n'est plus affiché, plus supprimable par
l'utilisateur, et compte dans son quota (F-019).

Résultat attendu : « une erreur au milieu d'une requête annule tout » : les fichiers écrits pendant la requête sont
supprimés si la transaction est annulée.

Conforme (testé) : exception après la création d'une matière (aucune matière écrite) ; exception après un import
.ics (aucun événement écrit) ; suppression d'une matière : notes gardées avec `subject_id = NULL`.
